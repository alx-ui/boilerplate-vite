# Comparison board

## Where

A **temporary** area that is clearly not the product: a separate page, a row labelled "Exploration · <topic> (temporary)", or an `explorations/<topic>/` folder. The real screens are never edited.

## Layout

```
[ Legend card ] [ Current ] [ A ] [ B ] [ C ]
```

- Every board is the same size and uses the same realistic data: the same people, the same numbers, the same long names.
- One option has small twists? Add sub-variants **A2, A3** next to A, not as new letters.
- A long set (5+): two rows, the legend card at the start of the first.

## Legend card template

```
<Topic> · options

Problem: <one or two sentences: what's wrong today, what a good result must do>

Recommended: <letter>, because <one sentence tied to the problem>

A · <name> — <idea in one line>
   Good at: …   Costs: …
B · <name> — …
   Good at: …   Costs: …
C · <name> (bolder) — …
   Good at: …   Costs: …

All options share: <fixes common to all, if any>
Open questions: <anything the person must decide>
```

## Presenting it in chat

1. Recommendation first: the letter and why.
2. One line per option.
3. Where the board is.
4. "Pick one, combine them (for example 'B with A's header'), or tell me none fit and why."

## After the pick

1. Apply the chosen option to the real screens.
2. Update the design system for any piece that changed, and propagate it to every screen that uses that piece.
3. Clear the temporary area. Remove the boards, or empty the page and rename it so it is obviously disposable.
4. Report what changed where.
