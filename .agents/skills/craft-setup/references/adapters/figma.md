# Adapter: Figma

Setup writes `DESIGN.md` as a file in the repo. Figma is only used for the optional references board and, through `craft-system` (create) or `craft-sync` (import), the foundations. Tool names vary by Figma MCP server; check your server's tool list.

| Skill verb | In Figma |
|---|---|
| Read what exists | Variables, styles and the component library; any existing guide page |
| References board (optional) | A page "References"; one frame per reference with its image and two lists, **Take** and **Avoid** |
| Look at it | Export or screenshot the frame |

This adapter has not been tested against a live Figma MCP yet. Reports are welcome.
